## Overview
A production-ready data and text processing library engineered using Test-Driven Development (TDD) principles with 100% test coverage via the Python unittest framework.

## Module Components
- string_data_processor.py: Core processing module providing text sanitization, token frequency mapping, and delimited numeric parsing.
- test_string_data_processor.py: Complete test suite with 14 automated unit tests covering nominal scenarios, boundary values, and exception handling.
- Week3_TDD_Testing_Report.docx: Formal technical report documenting test methodology, matrices, and TDD lifecycle.

## Running the Automated Tests
```bash
python3 -m unittest -v test_string_data_processor.py
```
